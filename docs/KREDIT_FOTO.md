# Kredit Foto Produk — Praktikum 7

Foto adalah **ilustrasi representatif** untuk tugas akademik dan **bukan foto resmi merek/kemasan produk**, kecuali dinyatakan lain. Pertahankan informasi ini dalam README dan halaman dokumentasi. Data harga, ukuran dan merek dalam aplikasi merupakan data simulasi, bukan klaim bahwa foto menggambarkan produk tersebut secara tepat.

Foto yang diunduh melalui API dapat berupa *thumbnail* (penurunan resolusi). Penampilan dengan `BoxFit.cover` dapat memangkas tepi foto pada UI; jelaskan modifikasi tampilan tersebut saat memberikan kredit.

**Penting:** Verifikasi kembali izin/lisensi di halaman Commons sebelum menerbitkan aset ke repository publik, terutama `Passion fruit juice.jpg`. Jika lisensi tidak sesuai, ganti dengan foto lain yang memiliki lisensi terbuka terverifikasi dan perbarui kredit.
